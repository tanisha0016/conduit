# Conduit

Conduit is a production-minded event processing platform built around Apache Kafka.

The project explores how to design reliable, observable and fault-tolerant event-driven systems using Kafka and Go.

## Goals

- Learn Apache Kafka through hands-on implementation
- Build reliable asynchronous event processing
- Explore partitions, consumer groups and offsets
- Implement retries and dead-letter handling
- Handle duplicate events and idempotent processing
- Monitor throughput, failures and consumer lag
- Experiment with failure recovery and replay
- Follow production-oriented software engineering practices

## Tech Stack

- Go
- Apache Kafka
- Docker
- PostgreSQL
- Prometheus
- Grafana
- GitHub Actions
